## 2. 詳細 / Details

### 2.1 `yolo26n.pt`

- **取得元のファイル / Upstream file:** `ultralytics/assets` リポジトリのリリース `v8.4.0` にある
  `yolo26n.pt`。取得 URL は
  `https://github.com/ultralytics/assets/releases/download/v8.4.0/yolo26n.pt`。
  この環境の `ultralytics` 8.4.211 は `ultralytics/utils/downloads.py` の
  `attempt_download_asset()` でこの URL を組み立てます（引数 `repo="ultralytics/assets"`、
  `release="v8.4.0"`）。
  / The `yolo26n.pt` file in release `v8.4.0` of the `ultralytics/assets` repository. The installed
  8.4.211 builds this URL in `attempt_download_asset()` with `repo="ultralytics/assets"` and
  `release="v8.4.0"`.
- **サイズ / Size:** 約 5.3 MB
- **取得方法 / How it is obtained:** ノートブックが初回に自動ダウンロードし、`assets/models/` に保存
  / downloaded automatically on first run and cached in `assets/models/`
- **学習データ / Training data:** COCO（80 クラス。`black_spot` / `scratch` は **含まれません** / **not included**）。
  これは **モデルが何で学習されたか** の記録です。同梱写真の出所とは別の情報です。
  / This records **what the model was trained on**; it says nothing about where the bundled
  photographs came from.
- **条件 / Terms:** 配布物（ホイール）には `licenses/LICENSE`（AGPL-3.0 本文）が同梱されています。
  メタデータは `License: AGPL-3.0`、`License-File: LICENSE` です。重みファイルについて別個の条項は
  同梱されていません。
  / The wheel ships `licenses/LICENSE` (the AGPL-3.0 text); its metadata records
  `License: AGPL-3.0` and `License-File: LICENSE`. No separate terms for the weight files are
  bundled.
- **判断について / What we do not claim:** この研修は、社内で学習目的に使う範囲でこのファイルを
  利用します。**「教育目的なら何でも自由に使える」という判断はしていません。** 製品への組み込み、
  再配布、外部への公開を行う場合は、実施者がライセンスを確認してください。
  / The course uses this file for internal training only. **We do not claim that educational use
  makes it free to reuse in any way.** Anyone embedding, redistributing or publishing it must
  check the licence themselves.

### 2.2 `bus.jpg`, `zidane.jpg`

- **置き場所 / Location:** `ultralytics/assets/`（インストールした `ultralytics` 8.4.211 の
  ホイール内 / inside the installed 8.4.211 wheel）
- **取得方法 / How it is obtained:** **ダウンロード不要**。パッケージに同梱されています
  / **no download needed**; bundled with the package
- **内容 / Content:** 人物・乗り物などの一般的な写真。PVC の欠陥ではありません
  / ordinary photos of people and vehicles; NOT PVC defects
- **記録されている条件 / What is recorded:** パッケージのホイールには AGPL-3.0 の `LICENSE` が
  1 つ入っているだけで、**`bus.jpg` と `zidane.jpg` それぞれの権利・撮影者・出所を示す表示は
  ありません**。パッケージのライセンスは **パッケージの配布条件** であり、同梱写真 1 枚ずつの
  権利を保証するものではありません。
  / The wheel carries a single AGPL-3.0 `LICENSE`; it carries **no notice of the rights,
  photographer or origin of `bus.jpg` and `zidane.jpg`**. The package licence is a
  **distribution condition for the package**, not a rights statement for each bundled photograph.
- **COCO との関係 / Relationship to COCO:** `yolo26n.pt` は COCO で事前学習されていますが、
  それは **モデルの学習データ** の説明です。**同梱写真が COCO の画像だという証拠はありません**
  （以前の版にそのような記述がありましたが、画像単位の裏付けが無いため削除しました）。
  / `yolo26n.pt` is pretrained on COCO, which describes **the model's training data**. There is
  **no asset-level evidence that the bundled photographs are COCO images**; an earlier version of
  this file said so without support, so that claim is removed.
- **なぜこれを使うか / Why these:** 「モデルが正しく動く」ことを、ネットワークに依存せず確認できるから
  / they let us verify the model works without depending on a download

### 2.3 ResNet-18（ImageNet）

- **取得方法 / How it is obtained:** `Patchcore(..., pre_trained=True)` が
  `download.pytorch.org` から自動取得し、`~/.cache/torch/hub/checkpoints/` にキャッシュ
  / fetched automatically and cached by torch
- **条件 / Terms:** torchvision のモデル定義に従います。**商用利用の可否はモデルごとに異なります**
  / per the torchvision model terms; commercial use differs per model
- **代替 / Alternative:** `pre_trained=False` にすると取得しません（精度は下がります / accuracy drops）

### 2.4 `open_reference/` の参考画像 / reference images

- **ファイル / Files:** `chelsea.png`、`camera.png`、`brick.png`、`VisA_samples.png`
- **取得方法 / How they are obtained:** `assets/scripts/download_reference_images.py` が
  **各ファイルを 1 回だけ** ダウンロードし、`assets/external_samples/open_reference/` に
  **改変せず** 保存します。SHA-256 とバイト数を照合し、一致しなければ保存しません。
  / The script downloads **each file once** into `assets/external_samples/open_reference/`
  **unchanged**, verifying the recorded SHA-256 and byte count before saving.
- **記録ファイル / Records:** 同じフォルダの `manifest.json`（URL・バイト数・SHA-256・作者・
  ライセンス・出典ページ）と `ATTRIBUTION.md`（1 行 1 ファイルの出所表）。
  / `manifest.json` (URL, bytes, SHA-256, author, licence, source page) and `ATTRIBUTION.md`
  (one row per file) sit in the same folder.
- **出所と条件 / Sources and terms:** `chelsea.png`（Stefan van der Walt）、`camera.png`
  （Lav Varshney）、`brick.png`（CC0Textures を scikit-image が処理）は
  **scikit-image のサンプルデータ（CC0 1.0）** です。`VisA_samples.png` は VisA データセットの
  概要図で、**CC BY 4.0**、Zou ほか（2022）の SPot-the-Difference の出典表示が必要です。
  / `chelsea.png`, `camera.png` and `brick.png` are **scikit-image sample data (CC0 1.0)**;
  `VisA_samples.png` is the VisA dataset overview under **CC BY 4.0**, credited to Zou et al.
  (2022), SPot-the-Difference.
- **使い方の範囲 / Scope of use:** **教材の中で参照するためだけ** に使います。
  **学習・較正・試験のデータとしては使いません。** 工場の PVC 写真でも、モデルの出力でも
  ありません。画像を切り抜いたり注釈を加えたりする場合は、元のファイルを残し、
  変更したことを明記してください。
  / These are **teaching references only**; they are **never used as training, calibration or test
  data**, and they are neither factory PVC photographs nor model outputs. If you crop or annotate
  one, keep the original and record that it was modified.

## 4. 実画像について / About real production images

実際の PVC の製造画像は **一切使用していません**。理由は 2 つです。

1. 社外秘情報の取り扱いが未整理であること
2. 撮影条件（カメラ・照明・距離）が未確定であること

第 2 週以降で、**許可を得たうえで** 実画像を収集します。

**No real production images are used**, for two reasons: confidential-data handling is
not yet agreed, and the imaging conditions (camera, lighting, distance) are not yet fixed. Week 2
collects real images **with permission**.

## 5. 更新のルール / How to keep this file current

新しい外部素材を使うときは、**必ずこのファイルに 1 行追加** してください。
追加できない素材は、研修で使わないでください。
行には、**取得元のファイル・リビジョン（URL かタグ）** と、**配布元が表示している条件** を
書きます。「教育目的だから大丈夫」といった判断はここに書きません。利用の可否は実施者が判断します。

Whenever a new external asset is used, **add a row to this file first**. If it cannot be
added, the asset must not be used in the course. Each row records **the exact upstream file and
revision (URL or tag)** and **the terms the distributor states**. Do not record an "it is
educational use, so it is fine" judgement here; the decision to use the asset belongs to the
person using it.
