# 参考出力の図 / Figures built from real runs

ここにある図は、**この研修を実際に実行して保存された結果**から作ったものです。
手描きのイメージや、AI が生成した画像ではありません。
These figures are built from outputs that this course actually produced and saved. Nothing here
is hand-drawn or generated by an image model.

## 作り方 / How they are made

```powershell
python assets\scripts\generate_reference_outputs.py
```

* 入力が無い場合は**図を作らずに失敗**し、理由を表示します（作り話で埋めません）。
  If a source file is missing, the script stops and prints why; it never invents a figure.
* 学習のやり直しや、大量の再推論はしません。保存済みの出力を読むだけです。唯一の例外は、
  YOLO の四角を描くための短い推論（ローカルの重み・`imgsz` 固定・ダウンロードなし）です。
  No retraining and no bulk re-inference; the script reads what was saved. The only exception is
  a short YOLO pass used to draw boxes, with local weights and a fixed `imgsz`.

## 注意 / Cautions

* 数値は **2026-11-12 の CPU 実行**のものです。あなたの環境で実行し直すと変わります。
  The numbers come from a CPU run on 12 Nov 2026 and will differ if you re-run the course.
* `training_results/` と `submissions/` は Git の対象外です（再生成できるため）。したがって
  これらの図だけが、実行結果を配布物に残す手段です。
  `training_results/` and `submissions/` are not tracked by Git, so these figures are the only way
  the saved results travel with the course material.
* 図の中に「参考出力 / Reference output」と書いてあるものだけが実測です。模式図・合成データとの
  区別は各図の中に明記しています。
  Only figures labelled "Reference output" are measured results; each figure states whether it is
  schematic or synthetic.
