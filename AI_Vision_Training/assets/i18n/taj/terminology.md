# Terminology — Tamang (taj-Deva)

用語表です。**未確認の訳語は作りません。** 空欄は「まだ決めていない」という意味です。
A term list. **No equivalent is invented here.** An empty cell means "not decided yet".

(`PatchCore`, `YOLO`, `image_AUROC`, `recall`, file paths, metric names) are **not** translated in
code or in data files; in prose they may take a Tamang explanation once one is reviewed.

## Rules for whoever confirms this table

1. Do not take a term from Nepali because it is convenient; Tamang is a different language with a
   different lexicon and grammar.
2. Record the variety (Eastern Tamang) and the script (Devanagari / Tamyig) beside every entry.
3. A confirmed term does **not** approve a sentence: sentence-level review is recorded per block with
   `<!-- taj-status: <cell id> approved -->`.
