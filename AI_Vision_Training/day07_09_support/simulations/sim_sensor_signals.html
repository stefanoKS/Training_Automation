センサ信号シミュレータ

Sensor signal simulator — 完全オフライン / fully offline. 架空のセンサのみ / fictional sensors only.

デジタル信号 / Digital signal

PLC入力ビット / PLC input bit: 0

1 = 検出 / detected、0 = 非検出 / not detected。ビットの意味は配線とプログラムで決まります / wiring and program define the meaning.

アナログ信号 / Analog signal

仮想圧力センサ 0–100 kPa → 50.0 kPa

同じ 0–100 kPa → 50.0 kPa

物理範囲と電気範囲の両方が必要です / both ranges are required.

エンコーダのパルス / Encoder pulses

PPR 500 → カウント / counts: 2000

PPR（パルス数）とカウント数は別です / PPR and decoded counts are different.

故障の見え方 / What failure looks like

「材料なし」と「センサ断線」が同じビットになる設計は危険です。/ A design where “no material” and “broken sensor” give the same bit is hazardous.
