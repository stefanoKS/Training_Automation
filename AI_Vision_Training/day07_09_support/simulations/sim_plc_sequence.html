押出し装置 PLCシミュレータ / Pusher machine PLC simulator

オフライン教育用・決定論的モデル / Offline training model, deterministic. 安全PLCではありません / Not a safety PLC.

安全境界 / Safety boundary: 本シミュレータは教育用です。実機の通電・空圧・安全機能の検証には使えません。非常停止・ガード・インターロック・再起動防止は、リスクアセスメントに基づく独立した安全系で設計・検証してください。
This is a training simulator. It cannot verify real energisation, pneumatics or safety functions. Emergency stopping, guards, interlocks and restart prevention require an independent safety system designed from a risk assessment.

入力 / Inputs

時間はシミュレーション上の値です。実機のスキャン周期・タイマー精度とは異なります。
Times are simulated; real scan and timer behaviour differ.

I/Oトレース / I/O trace

「STARTを押す」は100msのパルスです。押しっぱなしにしても、復電後に自動起動しません。
The START button produces a 100 ms pulse. Holding it does not restart the machine after power restoration.

確認すること / What to observe

  1. STARTを離してもRUNが続く（自己保持）/ RUN remains after START release.
  2. STOPでRUN、Y0、Y1、Y2がOFFになり、T0が0に戻る / STOP clears outputs and resets T0.
  3. 3秒でY1がONになる / Y1 turns on at 3 s.
  4. X3が来ないとF001でFAULTになる / missing X3 gives F001.
  5. リセットしてもY2はONにならない / reset does not start motion.
  6. 復電時にSTARTを保持していても自動起動しない / no restart from a held START.
