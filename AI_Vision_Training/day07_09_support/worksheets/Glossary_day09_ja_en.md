# 第9日 技術用語集（短縮版）/ Day 9 compact glossary

> 第9日のPDFは19ページ以内に収めるため、短縮版の用語集を使います。全用語は `Glossary_ja_en.md` にあります。
> The Day 9 PDF must stay within 19 pages, so it uses this compact glossary. The full list is in `Glossary_ja_en.md`.

| 用語 / Term | 意味 / Meaning |
|---|---|
| 撮像 / imaging | 対象を画像として取り込むこと / capturing an object as an image |
| 視野 / field of view (FOV) | カメラが写す範囲の実寸 / the physical area captured |
| 作動距離 / working distance (WD) | レンズから対象までの距離 / lens-to-object distance |
| 解像度 / resolution | 画像の画素数 / number of pixels |
| 画素 / pixel | 画像の最小単位 / smallest image element |
| 1ピクセルの実寸 / object-space sampling | 視野 ÷ 画素数 / FOV divided by pixels, in mm per pixel |
| 露光時間 / exposure time | 光を受ける時間 / time light is collected |
| ゲイン / gain | 信号の増幅度 / signal amplification |
| 動体ぶれ / motion blur | 露光中の移動によるぶれ / blur from movement during exposure |
| グローバルシャッター / global shutter | 全画素が同時に露光する方式 / all pixels expose together |
| ローリングシャッター / rolling shutter | 行ごとに時間をずらして露光する方式 / rows expose in sequence |
| エリアセンサ / area-scan camera | 2次元画像を撮るカメラ / captures a two-dimensional image |
| ラインセンサ / line-scan camera | 線を撮り、移動で画像を組み立てるカメラ / captures lines as the material moves |
| トリガ / trigger | 撮影を開始する信号 / signal that starts a capture |
| バックライト / backlight | 対象の後ろから当てる照明 / light from behind the object |
| 拡散照明 / diffuse lighting | 光を散らす照明 / lighting that scatters the light |
| 低角度照明 / low-angle lighting | 浅い角度で当てる照明 / shallow-angle lighting |
| グレア / glare | 強すぎる反射 / excessive reflection |
| 被写界深度 / depth of field | ピントが合う範囲 / in-focus range |
| 推論 / inference | 学習済みモデルで判定すること / producing an output from a trained model |
| 無効 / INVALID | 画像なし・推論失敗・通信失敗の結果 / result with no image, failed inference or failed link |
