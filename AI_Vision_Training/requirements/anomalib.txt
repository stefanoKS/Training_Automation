# 重要な注意 / IMPORTANT
#
# 1. anomalib は opencv-python-headless を要求し、ultralytics は
#    opencv-python を要求します。両方を同じ環境に入れると cv2 が二重になり、
#    どちらかが壊れます。だから環境を分けています。
#    anomalib requires opencv-python-headless while ultralytics requires
#    opencv-python. Installing both into one environment gives two cv2
#    distributions and breaks OpenCV. Hence two environments.
#
# 2. この環境には ultralytics を入れないでください。
#    Do NOT install ultralytics into this environment.
#
# 3. torch 2.10.0 の Windows ホイールは、この検証環境で
#    "Error loading c10.dll" により起動できませんでした。
#    torch 2.15.0 は同じ条件で正常に動作しました。
#    The torch 2.10.0 Windows wheel failed to load (c10.dll) on the verification
#    machine; torch 2.15.0 works. anomalib only requires torch>=2.10.
