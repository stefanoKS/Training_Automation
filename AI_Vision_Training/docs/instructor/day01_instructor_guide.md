### 説明する概念 / Key concepts

| 概念 / Concept | 説明の要点 / Key message |
|---|---|
| プログラム | 人間が書いた手順書。速い・疲れない・正確。**ルールが書ける仕事** に強い。同じ測定値と同じ設定なら同じ答えを返すが、測定そのものの正しさは別に確かめる |
| 自動化 | 決まった手順の繰り返し。判断のルールは人間が決める。**AI を使う処理もプログラムとして動く**。違うのはルールを人が書くかデータから決めるか |
| ルールベース AI | エキスパートシステム。専門家の知識を if 文などの規則として多数書き、組み合わせて推論する。学習はしない。幅の判定の if 文 1 つだけは通常の自動化で、これだけを AI とは呼ばない |
| 機械学習 | 例から規則性を見つけ、判定に使う数値を **データから** 決める。学習した決定木は if 文に書き下せるが、規則はデータが決めたもの |
| 深層学習 | 多層ニューラルネットワークを使う機械学習。ML の中の一部 |
| 学習 / 推論 | 学習はモデルの内部の数値（重み）をデータから決める、推論は決まった重みを当てはめる。**ラインで動くのは推論**。時間と回数は代表例で、定義ではない。重みと判定しきい値は別物 |
| 検査の 4 段階 | 撮る・測る・決める・動かすは **簡略化した例**。AI は「決める」だけに限らない（測定値の推定や領域の抽出にも使える） |
| 画素 | デジタル画像はすでに数値の表。8 ビットなら 0〜255。グレーは 高さ×幅、RGB は 高さ×幅×3 の数値を持つ |
| 解像度と欠陥 | 1 mm あたりの必要画素数 = 欠陥に必要な画素数 ÷ 欠陥の大きさ [mm]。3 画素はこの研修で選んだ目標値で、光学・コントラスト・ぼけ・ノイズで変わる。1 画素未満でも画素値は変わりうる |

### 実演 / Demonstration（10 分程度）

ノートブック 01 の Part 1〜Part 4 を、プロジェクタで実演してください。

1. `judge_width()` に 100.3 / 100.6 を入れて OK / NG を出す
2. 1000 個を一括判定し、NG 率を出す（**自動化の速さ** を見せる）
3. 正常品 200 枚から正常範囲を学習する（**学習の最小形** を見せる。特徴＝明るさは人が選び、
   平均と標準偏差はデータから決まる、と説明する）
4. 暗い日のデータで学習すると、正常品が NG になる（**データの偏り** を見せる）

Run Parts 1-4 of Notebook 01 on the projector: a hand-written rule, a batch run to show
speed, learning a normal range from 200 good products, then the same model trained on a dark day
mislabelling a good product.

### よくある誤解 / Common beginner misunderstandings

| 誤解 / Misunderstanding | 実際 / Reality |
|---|---|
| 「AI は何でも判断できる」 | 学習したことしかできない。**学習していない種類の欠陥は見逃す**（検出は設定したクラス名しか出せない） |
| 「AI は人間より正確」 | データが偏れば人間より悪い。しかも自信満々に間違える |
| 「AI はプログラムではない」 | AI もプログラムとして動く。違うのは **ルールを人が書くか、データから決めるか** |
| 「AI と機械学習は別物」 | 深層学習 ⊂ 機械学習 ⊂ AI の入れ子。ルールベース AI のように学習しない AI もある |
| 「ルールで書けるなら AI ではない」 | 規則を多数組み合わせて推論するならルールベース AI（エキスパートシステム）。単発のしきい値判定は通常の自動化。学習して得た規則は機械学習の結果 |
| 「画像処理の 4 段階のうち AI は『決める』だけ」 | 4 段階は簡略化した例。AI は測定値の推定や領域の抽出にも使える |
| 「黒点の検出は AI でないと無理」 | 照明を固定すれば、しきい値＋輪郭の通常の画像処理で足りることがある（第 2 日）。見え方がばらつく場合に学習する方法が選択肢になる |
| 「学習＝AI が賢くなる」 | 数値（パラメータ）が決まるだけ。**賢さはデータで決まる** |
| 「画像は特別なもの」 | ただの数値の表。第1日 02 で実際に書き換える |
| 「縮小すれば欠陥は消える」 | 消えるとは限らない。細部とコントラストが失われ、見つけにくく測りにくくなる |

## 理解度チェックの解答例 / Model answers

**（受講者には渡さないでください / do not hand these to learners）**

### ノートブック 01

1. **人がルールを書くか、データからルールを決めるか** が違いです。AI もプログラムとして動くので、
   「プログラムか AI か」ではなく「ルールの出どころ」で区別します。
   例：幅の判定は人がルールを書ける（100±0.5）。黒点は、照明を固定すれば暗い画素をしきい値で
   抜き出す通常の画像処理でも扱えることがある。見え方がばらついて人がしきい値を決めきれない
   ときに、例から決める方法（機械学習）が選択肢になる。
2. **機械学習のほうが広い。** 深層学習は多層ニューラルネットワークを使う機械学習の一種。
   どちらも AI の一部で、AI には学習しないルールベース AI（エキスパートシステム）もある。
3. **学習**：データを見てモデルの内部の数値（重み）を決める。**推論**：決まった重みを新しい画像に
   当てはめる。学習は長く大量のデータが要り、推論は短く 1 枚で足りるのが**代表例**だが、
   再学習もバッチ推論もあり、定義ではない。しきい値を変えても重みは変わらないが、判定は変わる。
4. 例：① 暗い日だけの写真で学習した（偏り）② 正常品 5 枚しか無い（量が足りない）
   ③ ラベルの間違い ④ 本番と照明・距離が違う。
5. **どちらを重く見るかは検査の要求で決まる。** 不良を出荷できない工程では見逃し（偽陰性）を
   最優先で減らす。ただし見逃しを減らすためにしきい値を厳しくすると、偽陽性（良品の誤判定）が
   増えてライン停止や手直しのコストが上がる。

### ノートブック 02

1. 640 × 480 × 3 = **921,600 個**。
2. **左上**。数学のグラフは左下が原点で上向きが正だが、画像は左上が原点で **下向きが正**。
3. RGB がすべて同じ値なので **灰色**（120 は中間の灰色）。
4. **縮小すると隣接画素がまとめられ、細部と周囲とのコントラストが失われる**。欠陥が消えるとは
   限らず、1 画素未満でも画素値は変わりうる。ただし形・位置の判断が難しくなり、見つけにくく
   測りにくくなる。必要な画素密度は「欠陥に必要な画素数 ÷ 欠陥の大きさ [mm]」で見積もる。
   3 画素はこの研修で選んだ目標値であり、光学・コントラスト・ぼけ・ノイズで変わる。
5. 画素の書き換えは、**画像の改変・欠陥のシミュレーション・マスク作成** に相当する。

### ノートブック 03

1. 分類は **画像 1 枚に 1 ラベル**、検出は **複数の四角＋クラス名＋confidence**。
2. セマンティックは **クラスごとのマスク**。離れた領域は連結成分として数えられるが、**接した欠陥は融合して区別できない**。インスタンスは欠陥ごとに ID を分ける。
3. **この研修の PatchCore は正常画像だけで学習する**（正常の特徴をメモリバンクに貯める）。ラベル付きの異常画像は、学習ではなく **しきい値の較正と評価** に使う。その代わり **何の欠陥かは分からない**。
4. **セグメンテーション**（画素単位で面積が分かる）。物体検出では四角の面積しか分からない。mm² で判定するには **校正**（1 画素 = 何 mm）が必要で、境界の扱い（以上／より大きい）も決める。
5. **セグメンテーション** が最も大変。画素単位で塗る作業が必要で、時間もかかり、判断もぶれる。
