# 講師用評価表 / Instructor assessment rubric

プログラミング構文や実際のアプリ完成度は採点しません。/ Do not grade code syntax or completion of a working app.

| 観点 / Criterion | 3：達成 / Meets | 2：一部 / Developing | 1：再確認 / Revisit |
|---|---|---|---|
| 理解 / Understanding | 問題と解決案を区別し、人とエージェントの責任を説明 / distinguishes problem/solution and human/agent roles | 一方は説明できる / explains one distinction | どちらも混同 / confuses both |
| 要件 / Requirements | 利用者・入力・出力と必須3件が具体的 / users, inputs, outputs and three essentials specific | 一部が曖昧 / some vague | 誰が何をするか不明 / user and behavior missing |
| 指示 / Agent communication | 計画承認・範囲・修正方法を含む / requests plan approval, scope and correction | 2点のみ / two of three | いずれも不明 / none clear |
| 検証 / Verification | 観察可能な受入基準5件、失敗時の期待値あり / five observable checks and expected error behavior | 3〜4件が具体的 / three or four concrete | 2件以下か「動く」のみ / at most two or vague |
| 安全 / Safety and scope | 架空データ・設備隔離・変更範囲を示す / fictional data, equipment exclusion and file scope | 2点 / two | 本番への接続を許す / permits production access |
| 費用 / Costs | 一回の依頼でも複数回のモデル呼出しで入力・出力料金が増えると説明 / explains multiple model calls and token charges | 「AIに料金がかかる」のみ / recognizes cost without mechanism | APIやサブスクリプションは常に無料だと断言 / assumes always free |

各行を1〜3で評価し、次の授業で改善できる具体的な一言を返します。/ Score each row 1–3 and give one actionable improvement for next time.
